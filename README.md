## 这是一个什么库

- 这是我**自己原创设计的角色**，不含任何他人作品的原图。
- 每个角色都在 `角色/<slug>/` 下，分 `01_立绘`、`02_三视图`、`03_补充设定`、`04_Q版`、`05_头像` 五个分区，每套都有一份 `设定.md` 记录角色要点。
- 文件名里的 **`a` / `b` 是两套平行服设**，不是同一套的两种配色：`a` = 幻想侧（奇幻或玄幻），`b` = 科技侧（科幻）。
- **`大 / 中 / 小` 是三档体型**，不是 Q 版；Q 版单独一个分区。
- 标准物料包是 **13 张**（6 立绘 + 2 三视图 + 1 补充设定 + 2 Q版 + 2 头像）。**没收满的角色也在库里，缺哪几项在下面写明了**。
- **本仓库所有图片右下角都带小水印**：`甶丶 · pixiv 72492206`。无水印原图不随仓库公开。

## 更新方式

- 这个库**持续更新**：补齐一个角色的缺项就提交一次，主线始终是 `main`。
- 每次更新都会写一条中文提交说明（改了什么、加了哪个角色的哪几项），历史见
  [Commits](https://github.com/fuzhu-ai-chan/ai-chan-designs/commits/main) 与 [`CHANGELOG.md`](CHANGELOG.md)。
- 引用时建议注明**版本或日期**（例如「截至 v1.3 / 2026-11-05」），因为物料会继续补齐。
