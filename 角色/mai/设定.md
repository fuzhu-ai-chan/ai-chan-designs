## 设定要点

微软自研大模型家族 **Microsoft AI（MAI）** 的非官方拟人形象。

视觉主源立足 `microsoft.ai` 官网独特的**「人文主义手绘水彩（Humanist Watercolor）」**美学，与微软标志性的 **2×2 四格窗色系**
（红橙 `#F25022` / 翠绿 `#7FBA00` / 天蓝 `#00A4EF` / 琥珀黄 `#FFB900`）。
以**奶油暖白**与**深石板靛灰**为基底，把四色化作清透柔和的淡彩，自然融入发尾、衣摆内衬与核心道具。

**人物固定锚**：纯人类少女 —— 温润奶油白大块面飘逸长发，**发尾清透四色淡彩渐变**（浅珊瑚橙 / 淡翠绿 / 清天蓝 / 暖鹅黄），
左侧细麻花辫、柔和清亮天青蓝双眸、腰间清晰 `MAI` 铭牌。

**双世界设定**：同一位少女，两套载体。

- **a = 奇幻侧 · 人文水彩绘梦师**：左侧细辫配冷银羽毛发簪；奶油象牙白宽大广袖礼裙配深石板靛灰修身马甲，
  腰系深石板灰蝴蝶结长丝带垂挂冷银 `MAI` 牌，前短后长飘逸裙摆（宽袖与裙摆内衬晕染清透四色水彩淡彩），
  深石板灰过膝袜配瓷白拼深灰低跟短靴；右手执冷银晶尖魔导长画笔，唤出官方多模态三微符（水彩花 / 代码 `{ }` / 声波气泡），
  左手托冷银镂空 2×2 四格玻璃水彩调色盘（左上红橙、右上翠绿、左下天蓝、右下琥珀黄）。
- **b = 科技侧 · Fluent 流线空间设计师**：左侧细辫换冷银流线羽翼发饰、左耳配冷银光学耳挂与轻透无框单边 AR 镜片；
  哑光瓷白流线中长未来风衣外披（下摆内衬流转清透四色全息光彩）、深石板靛灰高领斜裁连衣短裙、
  细银链垂挂磨砂玻璃 `MAI` 铭牌、纯白过膝科技丝袜配深灰拼瓷白冷银扣未来短靴；
  右手执纤细冷银触控笔点触身前无边框 Fluent 磨砂玻璃全息画布（左上 2×2 四色圆角窗标 + 发光花 / `{}` / 声波），
  左手托起悬浮半透明多层图层卡片。

**三档体型**：`小`（约 5 头身幼态）、`中`（约 6.2 头身，标准默认）、`大`（约 7.5 头身，成熟高挑丰满体量，保留少女面容）。
