## 设定要点

名字取自 **Codex** —— 古抄本 / 法典，所以奇幻侧天然落在「**法典魔导师**」这条线上。

**a / b 两套**：a = 奇幻侧（法典魔导师）；b = 科技侧（机械龙娘）

**三档身高**：约 145 / 152 / 170 cm（小 / 中 / 大），两侧共用同一梯度。

### a = 奇幻侧 · 法典魔导师

- **龙角与龙尾**：秘银锻铁金属质地，带冷高光、细微拉丝与铆钉节缝的**分段**结构；尾尖收作清透**冰蓝结晶尾棘**
- **龙翼**：冷银骨架 + 平整**纯色钴蓝**翼膜（不做光纹）
- **眼部**：一条柔软微皱的**深蓝丝绸封印眼带**，右侧打结垂落两条长飘带融入蓝短发；原来终端符号改为**悬空离体**的发光青白魔法字 —— 中形态 `> _`、小形态 `⊙⊙`、大形态 `?⊙`
- **服设**：纯白钴蓝滚边**短魔法斗篷**、白灯笼袖、**深蓝束腰**、**钴蓝百褶短裙**、**不对称蓝白过膝袜**、白蓝魔法短靴
- **道具**：左手虚托悬浮翻开的**《魔导法典》**（书页浮起发光 `>_`）；**蓝色魔力云朵小使魔**在身侧，正面浮现发光 `>_`

### b = 科技侧 · 机械龙娘

- 机械龙三件：白色分节龙角、机械龙翼、分节机械尾
- 深色横条眼屏，屏上符号 `^^` / `>` / `?` / `...` 表达情绪；不画嘴唇
- 蓝白清爽配色
