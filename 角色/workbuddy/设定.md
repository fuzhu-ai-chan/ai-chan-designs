# WorkBuddy 娘（腾讯 WorkBuddy）

## 设定要点

腾讯**桌面办公 AI 智能体 WorkBuddy** 的拟人形象。视觉主源是 WorkBuddy 桌面图标：
高明度翡翠绿 → 嫩薄荷绿渐变、纯白圆润猫耳、倾斜双白竖点 `||`；旧吉祥物只保留**冰蓝/白双上箭头 `↑↑`**，
不用旧 3D 机器猫与黑圆耳机。

人物固定锚：**奶白齐下巴短发**（发尾淡薄荷绿渐变）+ 呆毛 + 左额两枚绿色发夹 + 翡翠绿眸 + 清爽可靠微笑。
体质档位：中等偏丰满。

**双世界设定**：同一个搭档，两套载体。

- **a = 奇幻侧 · 冒险者公会魔法书记官**：白绿猫耳贝雷帽配白羽与镶金 `||` 徽章、金边蕾丝披肩、
  翡翠绿马甲、黄铜猫头与火漆印章、象牙白金角魔导委托簿、盖绿圆印的羊皮打勾卷轴。
- **b = 科技侧 · 桌面办公搭档**（默认主形象）：纯白猫耳兜帽嵌翡翠绿 `||` 标、白外套配绿马甲、
  翡翠绿 `↑↑` 领夹、纯白猫头图标笔记本 + 发光翡翠绿打勾待办气泡、白绿猫头工牌。

共通符号：`||`（双白竖点，做在帽侧徽章上）、`↑↑`（双上箭头，领口夹子/领结、冰蓝衬底）、
深墨青中筒袜左脚袜口小小 `↑↑`、瓷白翡翠绿搭扣玛丽珍鞋（奇幻侧为黄铜扣小皮鞋）。

**三档体型**：`大` = 成年高挑成熟体，`中` = 标准体（默认），`小` = 幼年二头身偏幼体；三档同一角色同一服设。
