## 核心设计亮点

1. **550W 起源优雅转译**：摒弃电影摄像头外观以彻底避嫌第三方版权，改为**右海蓝＋左绯红（虹膜内嵌纤细同心圆光学刻度微光环）异瞳**与裙侧 **`550W`** 极简科技飘带，保留命名初心且整体温和亲切。
2. **品牌蓝青 × 苔藓双意象**：双层水母头呈现 OpenMOSS 标志性深海蓝→浅天青渐变并挑染嫩苔藓绿；外搭半透明水雾露珠感短外套，衣摆融合 MOSS-Image 圆角方块像素渐变纹。
3. **全模态产品基因一眼直读**：左胸佩戴 `M + ∞` 轨道立体徽章；右手执纤细银白数位光笔在半空勾勒 `∞` 符号与天青全息布局画板（**MOSS-Image**）；左耳佩戴发光蓝青声波耳麦（**MOSS-TTS**）。
4. **活体开源「小苔藓」使魔**：将官方小苔藓从吊坠升级为漂浮肩侧、举着迷你画笔的扇贝边圆滚滚使魔，具备极佳的公仔、贴纸与官方表情包延展潜力。
5. **专属人设口癖**：安静稳重、记性极好，坚持把所有 `token` 正经叫作 **「词元」**（致敬邱锡鹏老师最早提出的中文译名）。
